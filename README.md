## Assets and motion

All five profile graphics are self-contained SVGs. Portrait PNGs and WOFF2 fonts are embedded inside the SVGs; original PNGs are also included under `assets/`. Animations use CSS and SMIL only, start at `0s`, and have readable static values. Reduced-motion preferences disable CSS entrances. GitHub may render SVG animation differently across clients, so `preview.html` is provided for local review.

Font licenses and inline brand-icon source references are included in [`licenses/`](./licenses/).
