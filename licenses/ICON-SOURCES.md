# Inline brand icon references

The GitHub and LinkedIn marks used in `assets/connect.svg` are bundled as inline vector paths; no brand icon is fetched at render time. Reference catalogs for reviewing current brand glyphs:

- GitHub — Simple Icons: https://simpleicons.org/?q=github
- LinkedIn — Simple Icons: https://simpleicons.org/?q=linkedin

The actual SVG uses inline paths so it remains self-contained and does not make runtime network requests.
